# GitHub collaboration lab

A small repository for practicing branches, co-authored commits, and pull-request merges.

## Exercise

1. Start from the default branch and create a topic branch.
2. Make a small documentation change.
3. Record account attribution with a blank line followed by a `Co-authored-by:` trailer in the commit message.
4. Open a pull request and merge it using a merge commit to retain the original attribution.
5. Inspect the merged commit and confirm GitHub links both account identities.

This exercise uses two accounts owned by the same person: @arieldaniely and @arieldanieli.
